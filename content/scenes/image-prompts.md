# Scene image prompts

Written by `app/scripts/generate-bank.mjs prompts`, for the Scenes that have no image yet.

1. In Antigravity (Nano Banana), attach `app/public/scenes/01-corner-cafe.jpg` as the style reference with every prompt.
2. Save each image as `app/public/scenes/<Scene id>.png` (or .jpg; any wide aspect ratio).
3. In `app/`, run `node scripts/generate-bank.mjs images`. It turns each into a 1024 px JPEG and links it to its Scene.

Every prompt ends with the same style instruction:

> Match the illustration style of the attached reference image exactly (line work, texture, palette, lighting), but draw a different scene. Warm editorial illustration. Calm, slightly muted palette of honey, slate blue and walnut, soft natural light. No readable text, no logos, no faces in close-up. Full-bleed wide 16:9 composition, no border or frame.
